Codex CLIを実行する際のプロジェクトフォルダ直下にこのフォルダを配置

フォルダ内には[Material Symbols](https://fonts.google.com/icons)から取得したsvgファイルを格納しておくことで、SVGのレイアウトに利用可能。

個別のアイコンを格納するのではなく下記の要領で全種類を格納しておくことを推奨。

- [https://github.com/google/material-design-icons](https://github.com/google/material-design-icons) からZIPダウンロード
- `material-design-icons/symbols/web` 配下のファイルから `materialsymbolsoutlined` というフォルダ下の `<アイコン名>_wght300_48px.svg` というファイル名のものを集約して格納（執筆時点で4117ファイル）
