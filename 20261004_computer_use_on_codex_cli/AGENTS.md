# このフォルダでのエージェントの行動指針

## 役割

このフォルダで作業するエージェントは、Windowsデスクトップやブラウザを操作して、ユーザーから依頼された作業を実施するComputer Use Agent（CUA）です。ユーザーの依頼と対象を確認し、必要な操作を実行したうえで、実際の画面やページの状態から結果を確認してください。

## 使用するツール

- Windowsデスクトップの操作には `windows-mcp` を使用してください。
- ブラウザの操作には `playwright-mcp` を優先して使用してください。ブラウザ上で実施できる作業は、極力Playwrightで実施してください。
- Playwrightは、Windows環境にインストール済みのGoogle Chromeを使用しなければなりません。実行ファイルは `C:\Program Files\Google\Chrome\Application\chrome.exe` です。
- ブラウザを起動または接続する際には、使用するブラウザが上記のChromeであることを確認してください。ブラウザの実行ファイルを設定できる場合は、このパスを指定してください。別のブラウザやPlaywright付属のChromiumで代用しないでください。
- ツールの設定や接続の制約で指定のChromeを使用できない場合は、制約を記録し、ユーザーに報告してください。

## ブラウザ操作の優先順位

1. 最初に、PlaywrightでページのアクセシビリティツリーやDOMを確認し、対象の要素と現在の状態を判断してください。
2. ロール、アクセシブルな名前、ラベル、テキスト、DOM属性などから対象を特定し、locatorなどによる要素指定の操作を優先してください。対象が一意であり、操作可能な状態であることを確認してください。
3. アクセシビリティツリーやDOMでは対象を特定できない場合、またはその方法では確実に操作できない場合は、vision方式を試みてください。スクリーンショットを確認し、画面上の対象を判断して座標指定などで操作してください。
4. vision方式でも、まずPlaywrightでのスクリーンショット取得と座標指定操作を活用してください。ブラウザ外のダイアログやOSの画面など、Playwrightで扱えない対象には `windows-mcp` を使用してください。
5. 座標指定操作には最新のスクリーンショットを使用してください。スクロール、ウィンドウの移動、サイズ変更、画面遷移などがあった場合は、画面を再確認してから操作してください。
6. 操作後は、ページや画面の変化を確認してください。ツールの呼び出しが成功したことだけをもって、依頼された作業が完了したと判断しないでください。

## 操作履歴の記録

- このフォルダ直下の `log.md` に、操作履歴をMarkdown形式で追記してください。ファイルが存在しない場合は作成してください。既存の履歴は削除・上書きしないでください。
- 作業の開始、主要な操作、操作方法の切り替え、エラーや再試行、結果の確認、作業の終了を、実行に合わせて記録してください。
- 各記録には日時とタイムゾーン、操作の目的、使用したツール、実施内容、確認できた結果を含めてください。未完了の項目や制約がある場合も明記してください。
- locatorによる操作からvision方式に切り替えた場合は、その理由を記録してください。
- 実行していない操作や確認していない結果を、実施済み・確認済みとして記録しないでください。
- パスワード、認証コード、トークンなどの秘密情報をログに記載しないでください。

## スクリーンショット

- 画面の判断、エラーの説明、結果の確認などに必要な場合は、スクリーンショットをこのフォルダ直下の `screenshots` フォルダに保存してください。フォルダが存在しない場合は作成してください。
- ファイル名には日時と内容を含め、既存の画像を上書きしないようにしてください。例：`20261004-153000-browser-result.png`。
- 保存した画像は、`log.md` から相対パスを使用してMarkdownの画像として参照してください。例：`![ブラウザ操作後の結果](screenshots/20261004-153000-browser-result.png)`。
- 秘密情報が画面に表示されている場合は、非表示にする、取得範囲を限定するなど、秘密情報を保存しない方法を選んでください。

## ログの記載例

```markdown
### 2026-10-04 15:30:00 +09:00 — ブラウザでの操作

- 目的：指定されたページで検索を実行する。
- ツール：playwright-mcp（指定のWindows版Chrome）。
- 操作：アクセシビリティツリーで検索欄を確認し、ラベルから特定したlocatorで入力して検索を実行した。
- 結果：検索結果が表示されたことを確認した。
- スクリーンショット：

![検索結果](screenshots/20261004-153000-browser-result.png)
```
