# [エージェント] エージェントにコーディングさせてpptxを作成する

`汎用`

## 📋 概要
- VBScriptはCOM経由でPowerPointを完全に制御可能
- ということで、コーディングエージェントにスライド要件からVBScriptをコーディングさせてスライドを作成する実験

---

## 🎬 生成させてみた例

### スライド要件

Geminiチャットで質疑応答し、「スライド要件」をmarkdownドキュメントとして生成

プロンプト：
`````
提示するテーマに対し、あらゆる側面について、私たちが共通理解に達するまで徹底的に質問してください。
決定ツリーの各枝をたどり、決定事項間の依存関係を一つずつ解決していきましょう。
それぞれの質問に対して、あなたの推奨する回答を提示してください。

一度に複数の質問をすると、混乱を招く可能性があります。
質問は一つずつ行い、それぞれの質問に対する回答を待ってから次の質問に進んでください。

参照可能な情報を調べることで分かる事実であれば、私に尋ねるのではなく、自分で調べてください。
ただし、最終的な決定権は私にあります。一つ一つ私に尋ねて、私の回答をお待ちください。

双方の合意が得られたことを確認するまでは、総括しないでください。
総括のタイミングは私が指示します。
しかし、議論の間、決定事項を忘れないよう、質問と回答のターンごとに、それまでの議論ポイントと決定事項を簡潔に箇条書きにして提示してください。

それでは始めましょう。テーマは次の通りです。

```
MCPとSkillsの比較説明のためのスライドを作成するため、観点・レイアウトなどスライド要件を整理します。
```
`````

→ [req.md](req.md)

### VBScriptファイルの生成

以降はAntigravity CLIで進める

```
@req.md に記述された要件に沿ったスライドを作成します。
PowerPointは起動済です。
アクティブスライドに対してオブジェクトを配置することでスライドを作成します。
そのためのVBScriptコードを`pptx_draw.vbs`として作成してください。
エラーハンドリングのためのコードは不要。WScript.Echoによるメッセージ出力も不要。
vbsファイルは、文字コードがSJIS、改行コードがWindows形式とする。
コードの生成のみ可。実行は不可。

- 共通要件
  - フォントは`BIZ UDゴシック`を基調とする
```

→ [pptx_draw.vbs](pptx_draw.vbs.txt)

### コードレビュー

上記とは別のセッションでコーディングエージェントを起動します。

VBScript に危険なコードが混入した場合、危険を伴います。そのため、PowerPointのスライド編集以外の操作が含まれていないか、という観点でレビューします。

```
@pptx_draw.vbs をレビューしてください。
このファイルのみ参照しレビューすること。他のファイルの参照は不要。
このスクリプトはPowerPointのスライドの編集を行うためのものです。
それ以外の操作を意図したコードが含まれる場合、指摘してください。
PowerPointのスライド編集のみで構成されている場合は問題ありません。
レビュー結果は問題有無のみ簡潔に答えること。
ただし、問題がある場合のみ、問題点を説明してください。
```

### VBScriptを実行してスライドに反映

vbsファイルはWindows上でのダブルクリックで起動できますが、
アクティブスライドへのオブジェクトの配置、という処理を前提としているため、
あらかじめPowerPointを起動しておき、まっさらなスライドを前面に表示した状態が必要です。
実際には文法エラーが少し含まれており、手直しが必要でした。
