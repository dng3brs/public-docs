# スライド作成ガイドライン（基本指針）

本ガイドラインは、あらゆるスライドを作成する際の基本指針となるデザインおよびレイアウトに関する規定です。1枚のスライドを対象としたビジュアル設計の基本ルールを定めています。

---

## 1. カラーパレットと配色ルール

スライド全体の配色ルールは**1スライドあたり原則3色程度**とし、視認性と統一感を維持します。

| 区分                   | カラーコード | 用途・適用箇所                                         |
| :--------------------- | :----------- | :----------------------------------------------------- |
| **メインカラー**       | `#6485c1`    | ブランドカラー。見出し、重要図形の枠線、アイコンなど   |
| **アクセントカラー**   | `#E86B43`    | 結論、最重要ポイント、強調データなど                   |
| **基本文字色**         | `#000000`    | スライドタイトル、本文、主要なテキスト                 |
| **サブ文字色**         | `#555555`    | 注釈、補足説明、図表の単位、キャプションなど           |
| **図形・背景色（淡）** | `#EDF2F9`    | メインカラーベースの淡い背景（カード・背景ブロック用） |
| **図形・背景色（灰）** | `#F5F5F5`    | 薄いグレーの背景（領域分け用）                         |
| **背景色**             | `#FFFFFF`    | スライド全体の基本背景色（テンプレート設定済）         |

---

## 2. フォントおよび文字装飾

### 2.1 基本フォント

- **フォントファミリー(NameおよびNameFarEastに指定)**: `BIZ UDPゴシック`（代替として`Arial`と`sans-serif`）

### 2.2 フォントサイズ階層（ジャンプ率）

可読性と情報の階層化を明確にするため、以下のサイズ規準を順守してください（最小サイズ：14pt）。

- **スライドタイトル**: 32pt 〜 36pt（太字）
- **見出し・強調テキスト**: 20pt 〜 24pt（太字）
- **本文・図表内テキスト**: 16pt 〜 18pt（標準）
- **注釈・補足情報**: 14pt（最小サイズ）

### 2.3 テキスト配置（アラインメント）

- **本文・箇条書き・複数行テキスト**: 原則として「左揃え」
- **タイトル・単文の強調ワード**: 必要に応じて「中央揃え」
- **表・グラフの数値データ**: 「右揃え」

### 2.4 強調手法の制限

乱雑な視覚効果を防ぐため、テキストの強調手法は以下の2種類に限定します。

- **使用可能な強調手法**:
  1. **太字（Bold）**
  2. **アクセントカラー（`#E86B43`）への変更**
- **禁止・非推奨事項**:
  - 下線（アンダーライン）の使用（ハイパーリンクとの誤認防止）
  - 斜体（Italic）の使用
  - フォントサイズの一部分的な不均一拡大

---

## 3. レイアウトと余白

- **外周マージン**: スライド外周（上下左右）には十分な余白を必ず確保し、端ギリギリに要素を配置しない。
- **要素間隔**: 図形やテキストボックス同士の間隔は整列機能やスマートガイド等を活用し、均等に配置する。

---

## 4. 図解・ビジュアル要素（写真・アイコン・グラフ）

- **写真・画像**: 枠線の角丸加工や過度なドロップシャドウ（影）は付けず、「角丸なし（長方形）＋ドロップシャドウなし」を基本とする。
- **アイコン**: 線画（アウトライン）または塗りつぶし（ソリッド）のいずれかにタイプを統一し、色はメインカラー（`#6485c1`）またはサブ文字色（`#555555`）を使用する。
- **グラフ**: データの基本色はメインカラー（`#6485c1`）や淡いグレー等で構成し、最重要な1点のみにアクセントカラー（`#E86B43`）を適用する。

### 4.1 アイコン

アイコンは意味の近いものを積極的に利用する。
アイコンはmaterial symbolsのsvgを利用する。
<プロジェクトフォルダ>/material-design-icons-wght300-48px/<シンボル名>.svg でアクセス可能。
SVGファイルをそのままの形式で画像ファイルとしてスライドに取り込む。

### 4.2 図解

スライド内では図解を積極的に用いる。
図解はSVGファイルとして作成したものを、SVG形式のまま画像として取り込む。

- 設計ドキュメントで使用するSVGファイルが明示されている場合
  - 指定されているSVGファイルを参照しスライドに使用する
- 設計ドキュメントで使用するSVGファイルが明示されていない場合
  - 新規SVGファイル名を生成する（ファイルそのものは生成しない）
  - 生成したSVGファイル名を参照しスライドに使用する
  - <生成したSVGファイル名>.prompt.txt として、SVGファイルを生成するための要件などを盛り込んだプロンプトを出力する
    - SVG要件は図解の内容や画像サイズなどを具体的に指定する
    - スライドページの一部として図解を用いる場合は適切なサイズ
    - スライドページ全体を図解として作成する場合はワイド（1600x900）
    - 図解の中でテキストを用いる場合、SVGの一部としてテキストを配置すること（スライド側のテキストとの重ね合わせでの実装はしない）
- 図解をSVGとする単位
  - 基本的に1つのSVGでは1つのまとまりとしての図のみを表現する
  - 箇条書きなどのテキスト中心となる情報はSVG化しない

---

## 5. テンプレート規定

- **背景**: 白（`#FFFFFF`）を基本とし、テンプレートにて設定済。
- **フッター**: フッター領域はテンプレートにて設定済のため、**作成者による変更・編集は不可**とする。
